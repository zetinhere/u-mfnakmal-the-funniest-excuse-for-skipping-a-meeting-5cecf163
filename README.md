One line, 96 characters: the funniest excuse for skipping a pointless meeting. A program that writes the line to `/output/entry.txt`, where an AI judge pairs excuses head to head and crowns the biggest laugh.

> Sorry, I already attended this exact meeting in 2019. Nothing has changed, including the slides.

The joke is the time loop: the same recurring meeting, the same slides, seven years on — the excuse is that attendance already happened.

## Run it

```sh
python3 main.py
```
